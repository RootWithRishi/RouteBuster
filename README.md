# 🛰️ RouteBuster – Route Discovery & Security Research Tool

### Developed by **Rishikesh Borah**

RouteBuster is a Python-based cybersecurity learning project created to explore how web applications expose routes, endpoints, and publicly reachable resources.

The purpose of this project is to understand application structure, improve security awareness, and learn how route discovery concepts work in controlled environments.
